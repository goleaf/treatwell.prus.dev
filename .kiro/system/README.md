# Kiro System Configuration

This folder contains system-level configurations and templates for the Laravel project.

## Structure

- `templates/` - Code generation templates
- `workflows/` - Automated workflow definitions
- `configs/` - System configuration files
- `scripts/` - Utility scripts for development
- `docs/` - System documentation and guides

## Usage

These files are used by Kiro to provide consistent development patterns and automation across the project.
